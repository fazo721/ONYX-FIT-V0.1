# ONYX FIT — Changelog

## v0.1.0 Alpha

Première version de test structurée.

### Inclus
- onboarding initial
- profil de base
- objectif
- nombre de séances/semaine
- durée des séances
- groupes musculaires prioritaires optionnels
- inventaire du home-gym
- génération simple du programme selon le matériel
- séance affichée exercice par exercice
- saisie charge / répétitions / RPE
- journal alimentaire de base
- calcul cible calories + macros
- recherche produit par code-barres avec Open Food Facts
- quantité consommée
- activité manuelle
- suivi poids / masse grasse de base
- base technique pour Supabase, IA et HealthKit

### Volontairement non finalisé en v0.1
- comptes utilisateurs cloud
- synchronisation Supabase
- IA recettes/programmes
- HealthKit réel
- notifications
- illustrations anatomiques spécifiques à chaque exercice
- Onyx spécifique à chaque exercice
- moteur de progression avancé
- version Pro/paiement

Le but de v0.1 est de valider le parcours utilisateur et relever les bugs avant d’ajouter les fonctions lourdes.
