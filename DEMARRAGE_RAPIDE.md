# Démarrage rapide — ONYX FIT v0.1

## PC
1. Installe Node.js LTS.
2. Clone ou télécharge le dépôt.
3. Ouvre un terminal dans le dossier.
4. Lance :
   npm install
5. Puis :
   npm run dev
6. Ouvre l’adresse affichée, généralement http://localhost:5173

## iPhone sur le même Wi‑Fi
Sur le PC, lance :
   npm run dev -- --host

Vite affichera une adresse réseau du type :
   http://192.168.1.xx:5173

Ouvre cette adresse dans Safari sur l’iPhone.

Si Windows demande l’autorisation du pare-feu, autorise Node.js sur le réseau privé.

## Important
v0.1 est une alpha de test. On valide d’abord les écrans et le parcours avant de connecter les fonctions cloud/IA/Santé.
